유튜브 강의 한국어 더빙 — 설치 안내

처음 설치한다면 아래 1번부터 따라 해 주세요.

1. ZIP 파일 압축 풀기

다운로드한 ZIP 파일을 압축 해제하세요.
압축을 푼 폴더 안에 extension 폴더, bin 폴더, 설치 파일들이 있는지 확인합니다.
ZIP 안에서 바로 실행하지 말고, 먼저 압축을 전부 풀어 주세요.
이 폴더는 사용 중에도 필요하므로 계속 보관할 위치에 두세요.

2. Chrome에 확장 등록하기

① Google Chrome을 엽니다.
② 맨 위 주소창에 아래 주소를 입력하고 Enter를 누릅니다.
   chrome://extensions
③ 오른쪽 위의 ‘개발자 모드’를 켭니다.
④ 화면 위쪽에 나타나는 ‘압축해제된 확장 프로그램을 로드’를 누릅니다.
⑤ 1번에서 압축을 푼 폴더 안으로 들어가 extension 폴더를 선택합니다.
   ZIP 파일이나 bin 폴더가 아니라, manifest.json이 들어 있는 extension 폴더입니다.
⑥ 확장 목록에 ‘강의 한국어 더빙’이 나타나면 등록 완료입니다.

Chrome 오른쪽 위 퍼즐 모양의 ‘확장 프로그램’ 버튼을 누르면 이 확장을 열 수 있습니다.
옆의 핀 버튼을 누르면 주소창 옆에 고정해 두고 편하게 열 수 있습니다.

3. 사용할 번역 방식 선택하기

[준원사무실codex를 사용할 경우]

내 컴퓨터에 Codex나 Tailscale을 설치할 필요가 없습니다.

① 확장을 열고 ‘준원사무실codex’를 선택합니다.
② 관리자가 알려 준 이메일과 비밀번호로 로그인합니다.
③ 사무실 서버 연결 권한을 묻는 Chrome 창이 뜨면 허용합니다.

로그인 후에는 로컬 모드로 바꿨다가 돌아와도 다시 로그인할 필요가 없습니다.
접속하려면 사무실 서버 컴퓨터가 켜져 있고 인터넷에 연결되어 있어야 합니다.
로그인이 안 되면 계정 정보가 맞는지 관리자에게 확인해 주세요.

[내 컴퓨터의 로컬 codex를 사용할 경우]

Codex CLI 설치와 Chrome 연결 등록이 필요합니다.
이미 Codex CLI를 설치하고 로그인했다면 ②부터 진행하세요.

① Codex CLI를 설치하고 로그인합니다.
   공식 설치 안내: https://developers.openai.com/codex/cli
   설치 후 터미널에서 codex를 실행하고 안내에 따라 로그인하세요.
   Windows에서는 Windows용 Codex CLI를 사용합니다.

② 압축을 푼 폴더에서 운영체제에 맞는 연결 설치 파일을 실행합니다.

   Windows
   install-windows.cmd 파일을 두 번 클릭합니다.

   macOS
   install.command 파일을 두 번 클릭합니다.
   실행 권한 오류가 나오면 해당 폴더에서 터미널을 열고 다음을 실행합니다.
   sh ./install.command

   Linux
   해당 폴더에서 터미널을 열고 다음을 실행합니다.
   sh ./install.command --no-gui

   연결 등록은 처음 한 번 하면 됩니다. 더빙할 때마다 실행할 필요는 없습니다.

③ 확장을 열고 ‘로컬 codex’를 선택합니다.

4. 더빙 시작하기

① 유튜브에서 보고 싶은 영상을 엽니다.
   설치 전에 열어 둔 영상이라면 페이지를 새로고침하세요.
② ‘강의 한국어 더빙’ 확장을 엽니다.
③ 사용할 번역 방식이 선택되어 있는지 확인하고 ‘더빙 켜기’를 누릅니다.
④ 준비가 끝나면 한국어 더빙이 시작됩니다.
   종료하려면 확장에서 ‘더빙 끄기’를 누르세요.

유튜브에서 제공하는 일반 자막이나 자동 생성 자막이 있는 영상에서 사용할 수 있습니다.

문제가 생겼을 때

• 로컬 codex 연결 실패라고 나오나요?
  터미널에서 codex가 실행되고 로그인되어 있는지 확인하세요.
  codex가 실행되는 터미널에서 위의 연결 설치 파일을 다시 실행해 주세요.
  그런 다음 chrome://extensions에서 이 확장의 새로고침 버튼을 누르고,
  유튜브 페이지도 새로고침해 주세요.

• 설치 폴더를 옮겼거나 삭제했나요?
  확장은 등록한 폴더의 파일을 계속 사용합니다.
  보관할 위치에 폴더를 둔 뒤 extension 폴더를 다시 등록하세요.
  로컬 codex를 사용한다면 연결 설치 파일도 다시 실행해 주세요.

• ‘유튜브 영상을 열거나 새로고침해 주세요’라고 나오나요?
  유튜브 영상 페이지를 열고 새로고침한 뒤 확장을 다시 열어 주세요.

업데이트할 때

더빙을 끄고 새 ZIP을 압축 해제한 뒤, 기존에 등록했던 폴더에 파일을 덮어씁니다.
로컬 codex를 사용한다면 연결 설치 파일도 다시 실행합니다.
chrome://extensions에서 ‘강의 한국어 더빙’의 새로고침 버튼(둥근 화살표)을 누르고,
유튜브 페이지도 새로고침하면 업데이트가 적용됩니다.
