로컬 codex 연결 방법

최초 한 번 연결 설치가 필요합니다. 확장만 등록하면 Codex CLI와 연결되지 않습니다.

  1. Codex CLI가 없으면 공식 설치 안내에 따라 설치합니다. 터미널에서 codex를 실행해 로그인하세요.
  2. 최신 배포 ZIP을 전부 압축 해제합니다. Windows는 install-windows.cmd, macOS는 install.command를 실행하세요. Linux는 압축 해제한 폴더에서 터미널을 열고 sh ./install.command --no-gui를 실행하세요.
  3. 이미 CLI가 있어도 위 연결 파일은 한 번 실행해야 합니다. Windows에서는 Windows용 CLI가 필요합니다. CLI를 찾지 못하면 codex가 실행되는 터미널에서 연결 파일을 다시 실행하세요.
  4. Chrome 확장 관리 화면에서 이 확장을 새로고침하고 유튜브도 새로고침하세요. 설치 폴더를 옮기거나 삭제하면 연결이 끊어집니다.

이전 확장 전용 ZIP에는 연결 파일이 없습니다. 연결 파일과 bin 폴더가 포함된 최신 ZIP을 사용하세요. 직접 설치하기 어려우면 준원사무실codex를 선택하고 로그인하세요.

허용된 계정으로 로그인해 주세요.

자막을 사무실 서버로 보내 번역합니다. 상대방 PC에는 Codex 설치가 필요 없습니다.
