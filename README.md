# 유튜브 강의 한국어 더빙

유튜브 자막을 내 PC 또는 사무실 서버의 Codex CLI로 번역하고 Chrome 한국어 음성으로 읽습니다. 번역 모델은 `gpt-6.1-terra`, 추론 수준은 `medium`이며 자연스러운 고등학교 선생님 말투를 사용합니다. 자막은 로그인된 Codex 계정으로 전송되고 해당 계정의 사용량이 적용됩니다.

## 설치

### 준원사무실codex 사용 (사용자 PC에 Codex 불필요)

1. 배포받은 확장 ZIP을 압축 해제하거나 저장소를 클론합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력하고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 누르고 `manifest.json`이 있는 `extension` 폴더를 선택합니다.
4. 유튜브 탭을 새로고침한 뒤 확장에서 **준원사무실codex**를 선택하고 관리자가 등록한 계정으로 로그인합니다. 처음 로그인할 때 서버 연결 권한을 허용합니다.
5. **더빙 켜기**를 누릅니다. 사용자 PC에는 별도 실행 파일이나 Tailscale을 설치하지 않습니다. 사무실 서버 노트북은 켜져 있고 인터넷에 연결되어 있어야 합니다.

### 로컬 codex 사용

Google Chrome과 로그인된 Codex CLI가 필요합니다. Python·Node.js·Go를 별도로 설치할 필요는 없습니다. Linux·macOS·Windows의 x64·ARM64 실행 파일이 포함되어 있습니다.

1. 저장소를 클론합니다.
2. macOS·Linux는 `./install.command`, Windows는 `install-windows.cmd`를 실행합니다. Windows에서는 WSL 내부가 아닌 Windows용 Codex CLI를 사용해야 합니다.
3. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**를 눌러 저장소의 `extension` 폴더를 선택합니다.
4. 유튜브 탭을 새로고침한 뒤 확장에서 **더빙 켜기**를 누릅니다.

업데이트할 때는 새 배포 파일을 받거나 `git pull` 후 확장 관리 화면의 새로고침 버튼을 누르고 유튜브 탭도 새로고침합니다. 내 PC 모드는 설치 파일도 다시 실행합니다. 저장소 경로를 옮긴 경우도 다시 설치·등록합니다.

## 동작

- 시작과 탐색 후에는 현재 위치부터 45초 분량의 자막을 먼저 번역하고 재생합니다. 남은 구간이 짧으면 남은 자막만 준비합니다. 재생 중에는 준비된 분량이 120초 아래로 줄면 최대 180초 앞까지 순차적으로 보충하며, 요청 하나에 최대 24개 문장 묶음을 보냅니다. 탐색 중 기존 요청이 진행 중이면 그 결과를 받은 직후 이동한 위치를 우선합니다. 번역이 재생을 따라가지 못하면 다시 준비한 뒤 이어갑니다.

- 자막을 확보할 때 CC를 켜고, 확보한 뒤 CC를 끕니다. 종료하면 시작 전 CC 상태로 복원합니다. 사용자가 중간에 직접 바꾼 상태는 덮어쓰지 않습니다.
- 일반 자막과 유튜브가 제공하는 자동 생성 자막을 사용할 수 있습니다. 둘 다 없을 때는 안내를 표시합니다. 새 자동 자막 생성이나 음성 인식 기능은 없습니다.
- 속도는 1.07배로 고정합니다. 확장에서 사용 가능한 한국어 음성을 선택할 수 있습니다. 선택은 저장되며 해당 음성을 사용할 수 없으면 기본 한국어 음성을 선택합니다. 한국어 음성이 없다면 운영체제에 한국어 음성을 추가해야 합니다.
- 문장 끝을 우선해서 자막을 묶습니다. 미완성 문장은 1.5초 이내의 자막 공백을 넘어 최대 40초·1,100자까지 이어 묶습니다. 번역이 늦거나 음성이 다음 설명 시작 시점까지 끝나지 않으면 영상이 잠시 기다립니다. 긴 묶음은 번역 대기 시간을 늘릴 수 있습니다.
- 수식은 첫 등장에 뜻과 빅오 표기를 함께 읽고 반복되면 표기만 읽습니다. 시간복잡도와 공간복잡도를 구별합니다. 탐색·재시작 시 설명을 다시 제공합니다. 미지원 수식은 원문 그대로 TTS에 전달합니다.
- 강조용 별표·밑줄·백틱은 제거하고 안쪽 내용만 번역합니다. 실제 수학 연산자는 무조건 제거하지 않습니다.
- 더빙 중 원음을 끄고, 종료·일시정지 시 이전 음소거 상태를 복원합니다. 번역 결과는 더빙 세션 메모리에만 보관합니다.

유튜브 페이지·자막 제공 방식 변경으로 자막 수집이 실패할 수 있습니다. 라이브와 Shorts는 지원 대상이 아닙니다. 영상 화면이나 원음의 발화를 직접 분석하는 방식은 아니며, 선택된 Chrome 음성 엔진에 따라 발음과 쉼이 달라집니다.

## 개발·검증

- `host/main.go`: 설치와 Chrome native messaging을 처리하는 Go 호스트
- `host/translation-prompt.txt`: 실행 파일에 포함되는 번역 지시
- `host/build.sh`: 유지보수용 6개 플랫폼 실행 파일 빌드 (Go 필요)
- `node --test tests/*.cjs`: 자막·재생·CC·수식 회귀 테스트
- `python3 tests/translation_contract.py`: Linux에서 가짜 Codex로 모델·추론 수준·응답 형식 검사
- `python3 tests/smoke_native.py`: 실제 Codex 번역 호출 검사 (로그인·네트워크 필요)

설치된 사용자는 개발 도구가 필요하지 않습니다. 테스트·라이선스 고지와 플랫폼별 실행 파일은 배포에 필요한 파일입니다. 로컬 모드와 원격 모드의 번역 엔진은 동일합니다.

## 사무실 원격 번역 (0.12.0)

확장에서 **로컬 codex / 준원사무실codex**를 선택합니다. 로컬 모드는 기존 설치 파일이 필요합니다. 사무실 모드 사용자는 Chrome 확장만 설치한 뒤 관리자가 허용한 이메일·비밀번호로 로그인합니다. 상대방에게 Codex나 Tailscale 설치는 필요하지 않습니다. 처음 로그인할 때 사무실 HTTPS 주소에 대한 확장 연결 권한을 승인합니다.

사무실 모드에서는 자막 텍스트만 고정된 사무실 HTTPS 서버로 보냅니다. 번역은 사무실 계정의 Codex 사용량에 포함됩니다. 한국어 음성은 사용자의 Chrome에서 읽습니다. 서버는 일반 명령 실행, 파일 열람, 모델 선택 API를 제공하지 않습니다.

- 로그인은 관리자 등록 계정만 허용하며 공개 회원가입 기능이 없습니다.
- 비밀번호는 무작위 솔트와 PBKDF2-SHA256 600,000회로 해시해 저장합니다.
- 로그인 세션은 14일입니다. 로컬 codex로 전환해도 사무실 로그인은 유지되며 다시 선택하면 재로그인 없이 사용할 수 있습니다. Chrome과 서버 재시작 후에도 유지되며, 비밀번호 변경·계정 차단 시 기존 세션을 거절합니다. 로그인 원문 비밀번호는 확장에 저장하지 않습니다.
- Chrome 저장소는 신뢰된 확장 화면만 접근하도록 제한합니다. 서버는 세션 토큰 해시만 저장합니다.
- 사용자별 동시 번역 1개, 서버 전체 동시 번역 2개, 사용자별 하루 200개 요청(UTC 기준)으로 제한합니다. 번역 실패 요청도 한도에 포함됩니다. 로그인 요청도 속도를 제한합니다.
- 서버는 자막·번역문을 로그나 데이터베이스에 보관하지 않습니다. 사용자·세션·요청 횟수는 저장소 밖의 사용자 설정 폴더에 저장합니다.

### 서버 운영

서버 PC에서 먼저 기존 설치 파일로 Codex 경로를 등록한 뒤 운영체제에 맞는 실행 파일에 `server` 인자를 줍니다. HTTP 서버는 `127.0.0.1:8765`에만 바인딩합니다. 인터넷 공개는 해당 포트만 HTTPS 리버스 프록시로 연결합니다. 현재 배포는 Tailscale Funnel을 사용합니다. 다른 사무실 서버로 옮길 때는 `extension/remote-config.js`와 manifest의 선택적 호스트 권한 주소를 함께 바꿔야 합니다.

관리자가 계정을 추가하거나 비밀번호를 바꾸려면 `bin/host-linux-amd64 user add 이메일`을 실행하고 비밀번호를 표준입력으로 전달합니다. 비밀번호를 명령행 인자·스크립트·셸 히스토리에 기록하지 마세요. 관리 콘솔을 대체하는 관리 명령은 서버 컴퓨터에서만 실행합니다.

- `bin/host-linux-amd64 user list`: 계정 목록
- `bin/host-linux-amd64 user revoke 이메일`: 접근 차단
- 사용자 데이터: Linux에서는 `~/.config/korean-dubber-server/` (폴더 0700, 파일 0600)

개발 검증: `go test ./host`, `node --test tests/*.cjs`. 빌드에는 Go 1.26 이상이 필요하며 외부 Go 모듈 의존성은 없습니다.
