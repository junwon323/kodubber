# 유튜브 강의 한국어 더빙

Chrome에서 유튜브 강의의 시간 자막을 읽고, 컴퓨터에 설치된 Codex CLI로 한국어 번역을 생성해 영상에 맞춰 읽습니다. 번역 요청에는 자막 텍스트가 포함되며 로그인한 Codex 계정의 네트워크 연결 및 사용량이 적용됩니다.

## 설치

Google Chrome과 로그인한 Codex CLI를 준비하세요. 설치와 더빙에는 Python, Node.js, Go, 관리자 권한이 필요하지 않습니다. Linux, macOS, Windows의 x86-64 및 ARM64 실행 파일이 저장소에 포함되어 있습니다.

1. 클론한 저장소 폴더에서 사용하는 운영체제에 맞는 파일을 한 번 실행하세요.

   | 운영체제 | 실행 방법 |
   | --- | --- |
   | macOS (Apple Silicon·Intel) | Finder에서 `install.command`를 더블클릭하거나 터미널에서 `./install.command` 실행 |
   | Windows (x64·ARM64) | 파일 탐색기에서 `install-windows.cmd`를 더블클릭하거나 PowerShell에서 `.\install-windows.cmd` 실행 |
   | Linux (x64·ARM64) | 터미널에서 `./install.command` 실행 |

   Windows에서는 일반 PowerShell에서 `codex login status`가 동작해야 합니다. Windows용 설치기는 현재 사용자의 Chrome에 연결 정보를 등록합니다. WSL 내부의 Linux용 Codex는 이 설치기에서 사용할 수 없습니다.

2. Mac과 Windows에서는 설치기가 Chrome 확장 관리 화면과 `extension` 폴더가 선택된 Finder 또는 탐색기를 엽니다. Chrome에서 **개발자 모드**를 켜고 선택된 폴더를 관리 화면으로 끌어다 놓으세요. 수동 등록은 Chrome에서 `chrome://extensions` → **개발자 모드 → 압축해제된 확장 프로그램을 로드**를 누르고 설치 메시지에 표시된 폴더를 선택하면 됩니다.
   Linux에서도 설치 후 Chrome 확장 관리 화면과 extension 폴더가 열립니다. 파일을 더블클릭해 실행되지 않으면 저장소 폴더의 터미널에서 `./install.command`를 실행하세요.

3. 유튜브 강의를 새로고침하고 자막(CC)을 켠 뒤 확장에서 **더빙 켜기**를 누르세요.

기존 설치를 업데이트할 때는 `git pull` 후 운영체제에 맞는 설치 파일을 실행하고 Chrome 확장 관리 화면에서 새로고침하세요. 저장소 경로를 옮겼을 때도 다시 등록하고 새 경로의 확장을 로드하세요. 한국어 음성을 찾지 못한다는 메시지가 나오면 목소리 목록에서 Supertonic 로컬 음성을 선택하거나 Chrome에서 사용할 수 있는 한국어 TTS 엔진을 준비하세요.

## 로컬 한국어 음성

팝업의 **더빙 목소리**에서 Supertonic 여성 1–5 또는 남성 1–5를 선택하고 **목소리 미리듣기**를 누르세요. 처음 사용하는 목소리 모델은 약 400MB를 Hugging Face에서 내려받아 브라우저 디스크 캐시에 저장합니다. 다운로드한 모델의 SHA-256과 크기를 고정된 목록과 비교합니다. 이후 음성 합성은 컴퓨터에서 이루어지며 음성 API 키나 호출 요금이 필요하지 않습니다. 번역은 기존 Codex 로그인을 사용합니다.

- 미리듣기가 끝나거나 더빙을 끄면 음성 작업 스레드와 숨김 재생 문서를 종료해 모델 메모리를 반환합니다. 모델 파일은 다음 실행을 위해 디스크에 남습니다.
- CPU 한 개를 사용하는 WebAssembly 구현입니다. 생성 중 CPU·메모리를 사용하며 다른 작업에 영향을 줄 수 있습니다. 이 Linux 컴퓨터의 샘플에서는 7초 음성 생성에 약 8–10초, 프로세스 메모리에 약 0.8GB가 필요했습니다. 브라우저별 실제 수치는 다릅니다.
- 음성 생성 중에는 영상이 기다립니다. 재생 중 다음 문장을 미리 생성하고 최대 3개의 합성 결과를 메모리에 보관합니다.
- Chrome의 확장 관리 화면에서 확장을 새로고침하고 유튜브 탭도 새로고침해야 업데이트가 적용됩니다. 추가된 모델 다운로드 권한을 확인해 주세요.
- 기본 로컬 음성은 F1입니다. 이전에 목소리를 선택했다면 그 설정이 유지되므로 로컬 목소리를 직접 선택하세요.
- 코드와 실행 런타임은 확장에 포함됩니다. 원격에서는 모델과 목소리 데이터만 받습니다. Supertonic 아카이브와 ONNX Runtime Web을 사용하며 라이선스와 고정 버전은 `extension/vendor/NOTICE.md`에 기록되어 있습니다.

## 목소리와 번역 스타일

팝업에서 Chrome이 제공하는 한국어 목소리와 번역 스타일(표준 강의체, 친근한 설명체, 간결한 기술 해설)을 선택하세요. 말하기 속도는 0.75·0.9·1·1.1배 중 선택하며 기본값은 0.9배입니다. 자막 길이나 영상 배속에 따라 음성을 자동 가속하지 않습니다. 선택은 다음 강의에도 유지됩니다. 더빙 중에 바꾸려면 잠시 끄고 선택한 뒤 다시 켜세요.

## 강의 듣기

유튜브 일반 영상 페이지를 새로고침하고 원본 언어 자막(CC)을 켭니다. 확장 아이콘에서 **더빙 켜기**를 누릅니다. 같은 버튼을 다시 누르면 더빙을 끄고 기존 음소거 상태를 복원합니다. 팝업을 닫아도 켠 상태는 유지됩니다. 번역이 준비되지 않은 구간에서는 영상이 자동으로 잠시 멈춥니다. 번역이 준비되면 재생을 이어갑니다. 한국어 설명이 다음 설명 시작 위치까지 끝나지 않으면 영상이 기다렸다가 음성 완료 후 계속됩니다.

- 플레이어의 텍스트 트랙, 페이지 로드 이후 유튜브가 받은 자막 응답, 현재 영상의 플레이어 자막 트랙을 순서대로 확인합니다. JSON·XML·VTT 형식을 지원합니다. 확장을 업데이트한 뒤에는 유튜브 탭을 새로고침해야 자막 응답 수집기가 적용됩니다. 유튜브가 자막 경로 또는 응답 형식을 바꾸거나 서명 요청을 재사용할 수 없으면 자막 파일을 선택하세요. UTF-8 VTT 및 SRT를 지원합니다.
- 인접한 자막 조각을 합쳐 첫 묶음은 최대 6구간, 이후에는 최대 24구간씩 번역합니다. 번역 결과는 현재 더빙 세션 메모리에 보관합니다. 영상 이동 시 새 위치부터 재생하며, 준비 중인 구간에서는 영상이 기다립니다.
- 발화 중에는 원음을 끕니다. 구간이 끝나거나 일시정지·종료하면 기존 음소거 상태를 복원합니다. 말하기 속도를 유지하며 문장을 끝까지 읽습니다. 설명이 길어지면 영상이 잠시 멈출 수 있습니다. 자막의 시작 시각으로 영상 속 설명 위치를 찾으며 화면 내용이나 원음의 발화를 분석하는 방식은 아닙니다.
- 한국어 음성이 없거나 호스트 등록에 실패하면 팝업에서 오류를 확인할 수 있습니다. 자막 없는 영상의 음성 인식, 라이브 스트림, Shorts는 지원 대상에서 제외합니다.

## 검증

- `node --test tests/*.cjs` — 가상 영상 시계와 음성 메시지로 자막 묶기, 번역 요청, 탐색, 일시정지, 배속 및 음소거 복원을 검사합니다.
- `python3 tests/smoke_native.py` — 잘못된 요청을 거부하는지 검사하고 Codex로 예시 자막 한 줄을 실제 번역합니다. 로그인과 네트워크가 필요합니다.
- 실제 설치 후 강의에서 더빙 시작, 탐색, 일시정지, 종료를 차례로 확인하세요. 한국어 발음과 재생 품질은 선택된 TTS 엔진에 따라 달라집니다.
