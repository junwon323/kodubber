# 유튜브 강의 한국어 더빙

유튜브 자막을 컴퓨터에 설치된 Codex CLI로 번역하고 Chrome 한국어 음성으로 읽습니다. 번역 모델은 `gpt-6.1-terra`, 추론 수준은 `medium`이며 자연스러운 고등학교 선생님 말투를 사용합니다. 자막은 로그인된 Codex 계정으로 전송되고 해당 계정의 사용량이 적용됩니다.

## 설치

Google Chrome과 로그인된 Codex CLI가 필요합니다. Python·Node.js·Go를 별도로 설치할 필요는 없습니다. Linux·macOS·Windows의 x64·ARM64 실행 파일이 포함되어 있습니다.

1. 저장소를 클론합니다.
2. macOS·Linux는 `./install.command`, Windows는 `install-windows.cmd`를 실행합니다. Windows에서는 WSL 내부가 아닌 Windows용 Codex CLI를 사용해야 합니다.
3. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**를 눌러 저장소의 `extension` 폴더를 선택합니다.
4. 유튜브 탭을 새로고침한 뒤 확장에서 **더빙 켜기**를 누릅니다.

업데이트할 때는 `git pull` 후 설치 파일을 실행하고 확장 관리 화면과 유튜브 탭을 새로고침합니다. 저장소 경로를 옮긴 경우도 다시 설치·등록합니다.

## 동작

- 자막을 확보할 때 CC를 켜고, 확보한 뒤 CC를 끕니다. 종료하면 시작 전 CC 상태로 복원합니다. 사용자가 중간에 직접 바꾼 상태는 덮어쓰지 않습니다.
- 일반 자막과 유튜브가 제공하는 자동 생성 자막을 사용할 수 있습니다. 둘 다 없을 때는 안내를 표시합니다. 새 자동 자막 생성이나 음성 인식 기능은 없습니다. UTF-8 VTT·SRT 파일을 직접 선택할 수도 있습니다.
- 속도는 1.05배로 고정합니다. 기존 한국어 목소리 설정이 있으면 유지하고, 사용할 수 없으면 제공되는 한국어 목소리를 자동 선택합니다. 한국어 음성이 없다면 운영체제에 한국어 음성을 추가해야 합니다.
- 문장 끝을 우선해서 자막을 묶습니다. 미완성 문장은 1.5초 이내의 자막 공백을 넘어 최대 40초·1,100자까지 이어 묶습니다. 번역이 늦거나 음성이 다음 설명 시작 시점까지 끝나지 않으면 영상이 잠시 기다립니다. 긴 묶음은 번역 대기 시간을 늘릴 수 있습니다.
- 수식은 첫 등장에 뜻과 빅오 표기를 함께 읽고 반복되면 표기만 읽습니다. 시간복잡도와 공간복잡도를 구별합니다. 탐색·재시작 시 설명을 다시 제공합니다. 미지원 수식은 원문 그대로 TTS에 전달합니다.
- 강조용 별표·밑줄·백틱은 제거하고 안쪽 내용만 번역합니다. 실제 수학 연산자는 무조건 제거하지 않습니다.
- 더빙 중 원음을 끄고, 종료·일시정지 시 이전 음소거 상태를 복원합니다. 번역 결과는 더빙 세션 메모리에만 보관합니다.

유튜브 페이지·자막 제공 방식 변경으로 자막 수집이 실패할 수 있습니다. 라이브와 Shorts는 지원 대상이 아닙니다. 영상 화면이나 원음의 발화를 직접 분석하는 방식은 아니며, 선택된 Chrome 음성 엔진에 따라 발음과 쉼이 달라집니다.

## 개발·검증

- `host/main.go`: 설치와 Chrome native messaging을 처리하는 Go 호스트
- `host/translation-prompt.txt`: 실행 파일에 포함되는 번역 지시
- `host/build.sh`: 유지보수용 6개 플랫폼 실행 파일 빌드 (Go 필요)
- `node --test tests/*.cjs`: 자막·재생·CC·수식 회귀 테스트
- `python3 tests/translation_contract.py`: Linux에서 가짜 Codex로 모델·추론 수준·응답 형식 검사
- `python3 tests/smoke_native.py`: 실제 Codex 번역 호출 검사 (로그인·네트워크 필요)

설치된 사용자는 개발 도구가 필요하지 않습니다. 테스트·라이선스 고지와 플랫폼별 실행 파일은 배포에 필요한 파일입니다. 현재 버전에는 원격 번역 서버 기능이 없습니다.
