# 유튜브 강의 한국어 더빙

Chrome에서 유튜브 강의의 시간 자막을 읽고, 컴퓨터에 설치된 Codex CLI로 한국어 번역을 생성해 영상에 맞춰 읽습니다. 번역 요청에는 자막 텍스트가 포함되며 로그인한 Codex 계정의 네트워크 연결 및 사용량이 적용됩니다.

## 설치

1. Linux 또는 macOS에 Google Chrome, Python 3.9 이상, Codex CLI를 준비합니다. 터미널에서 `codex login status`로 로그인을 확인합니다. CLI는 `codex exec --help`에 `--ignore-user-config`, `--ephemeral`, `--output-schema`가 표시되는 버전이 필요합니다.
2. 저장소 루트에서 `python3 host/install.py`를 실행합니다. 현재 사용자 Chrome에 로컬 번역 프로그램을 등록합니다. 저장소를 옮기면 이 명령을 다시 실행하세요.
3. Chrome에서 `chrome://extensions`를 열고 **개발자 모드 → 압축해제된 확장 프로그램을 로드**를 선택한 다음 이 저장소의 `extension` 폴더를 엽니다.
4. Chrome에서 사용할 수 있는 한국어 TTS 음성을 준비합니다. Linux에서는 한국어 음성을 제공하는 Chrome TTS 엔진 확장이 필요할 수 있습니다.

## 강의 듣기

유튜브 일반 영상 페이지를 새로고침하고 원본 언어 자막(CC)을 켭니다. 확장 아이콘에서 **더빙 시작**을 누릅니다. 처음 번역하는 동안 영상을 일시정지해 두면 첫 설명부터 들을 수 있습니다. 상태가 **더빙 준비됨**으로 바뀌면 영상을 재생합니다.

- 플레이어의 텍스트 트랙 또는 이 영상에서 Chrome이 요청한 유튜브 자막을 읽습니다. 유튜브가 자막 경로 또는 응답 형식을 바꾸거나 서명 요청을 재사용할 수 없으면 자막 파일을 선택하세요. UTF-8 VTT 및 SRT를 지원합니다.
- 인접한 자막 조각을 합쳐 최대 24구간씩 번역합니다. 번역 결과는 현재 더빙 세션 메모리에 보관합니다. 영상 이동 시 새 위치부터 재생하며, 준비 중인 구간에서는 원음이 나옵니다.
- 발화 중에는 원음을 끕니다. 구간이 끝나거나 일시정지·종료하면 기존 음소거 상태를 복원합니다. 빠른 강의에서는 다음 구간에 맞춰 긴 발화 끝이 잘릴 수 있습니다.
- 한국어 음성이 없거나 호스트 등록에 실패하면 팝업에서 오류를 확인할 수 있습니다. 자막 없는 영상의 음성 인식, 라이브 스트림, Shorts는 지원 대상에서 제외합니다.

## 검증

- `node --test tests/player.cjs` — 가상 영상 시계와 음성 메시지로 자막 묶기, 번역 요청, 탐색, 일시정지, 배속 및 음소거 복원을 검사합니다.
- `python3 tests/smoke_native.py` — 잘못된 요청을 거부하는지 검사하고 Codex로 예시 자막 한 줄을 실제 번역합니다. 로그인과 네트워크가 필요합니다.
- 실제 설치 후 강의에서 더빙 시작, 탐색, 일시정지, 종료를 차례로 확인하세요. 한국어 발음과 재생 품질은 선택된 TTS 엔진에 따라 달라집니다.
