# 유튜브 강의 한국어 더빙

Chrome에서 유튜브 강의의 시간 자막을 읽고, 컴퓨터에 설치된 Codex CLI로 한국어 번역을 생성해 영상에 맞춰 읽습니다. 번역 요청에는 자막 텍스트가 포함되며 로그인한 Codex 계정의 네트워크 연결 및 사용량이 적용됩니다.

## 설치

Google Chrome과 로그인한 Codex CLI를 준비하세요. 설치와 더빙에는 Python, Node.js, Go, 관리자 권한이 필요하지 않습니다. Linux와 macOS의 x86-64 및 ARM64 실행 파일이 저장소에 포함되어 있습니다.

1. 클론한 저장소 폴더에서 다음 명령을 실행하세요. macOS에서는 Finder에서 `install.command`를 더블클릭해도 됩니다.

   ```sh
   ./install.command
   ```

2. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축해제된 확장 프로그램을 로드**를 선택하세요. 설치 완료 메시지에 표시된 `extension` 폴더를 여세요.
3. 유튜브 강의를 새로고침하고 자막(CC)을 켠 뒤 확장에서 **더빙 켜기**을 누르세요.

기존 설치를 업데이트할 때는 `git pull` 후 `./install.command`를 실행하고 Chrome 확장 관리 화면에서 새로고침하세요. 저장소 경로를 옮겼을 때도 다시 등록하고 새 경로의 확장을 로드하세요. 한국어 음성을 찾지 못한다는 메시지가 나오면 Chrome에서 사용할 수 있는 한국어 TTS 엔진이 필요합니다.

## 강의 듣기

유튜브 일반 영상 페이지를 새로고침하고 원본 언어 자막(CC)을 켭니다. 확장 아이콘에서 **더빙 켜기**을 누릅니다. 같은 버튼을 다시 누르면 더빙을 끄고 기존 음소거 상태를 복원합니다. 팝업을 닫아도 켠 상태는 유지됩니다. 처음 번역하는 동안 영상을 일시정지해 두면 첫 설명부터 들을 수 있습니다. 상태가 **더빙 준비됨**으로 바뀌면 영상을 재생합니다.

- 플레이어의 텍스트 트랙 또는 이 영상에서 Chrome이 요청한 유튜브 자막을 읽습니다. 유튜브가 자막 경로 또는 응답 형식을 바꾸거나 서명 요청을 재사용할 수 없으면 자막 파일을 선택하세요. UTF-8 VTT 및 SRT를 지원합니다.
- 인접한 자막 조각을 합쳐 첫 묶음은 최대 6구간, 이후에는 최대 24구간씩 번역합니다. 번역 결과는 현재 더빙 세션 메모리에 보관합니다. 영상 이동 시 새 위치부터 재생하며, 준비 중인 구간에서는 원음이 나옵니다.
- 발화 중에는 원음을 끕니다. 구간이 끝나거나 일시정지·종료하면 기존 음소거 상태를 복원합니다. 빠른 강의에서는 다음 구간에 맞춰 긴 발화 끝이 잘릴 수 있습니다.
- 한국어 음성이 없거나 호스트 등록에 실패하면 팝업에서 오류를 확인할 수 있습니다. 자막 없는 영상의 음성 인식, 라이브 스트림, Shorts는 지원 대상에서 제외합니다.

## 검증

- `node --test tests/player.cjs` — 가상 영상 시계와 음성 메시지로 자막 묶기, 번역 요청, 탐색, 일시정지, 배속 및 음소거 복원을 검사합니다.
- `python3 tests/smoke_native.py` — 잘못된 요청을 거부하는지 검사하고 Codex로 예시 자막 한 줄을 실제 번역합니다. 로그인과 네트워크가 필요합니다.
- 실제 설치 후 강의에서 더빙 시작, 탐색, 일시정지, 종료를 차례로 확인하세요. 한국어 발음과 재생 품질은 선택된 TTS 엔진에 따라 달라집니다.
